# K-Nearest Neighbors (KNN)

## Project Overview
This project demonstrates the implementation of the K-Nearest Neighbors (KNN) algorithm using the Social Network Ads dataset.

## Objective
To build a machine learning model that predicts whether a person will purchase a product based on their age and estimated salary.

## Algorithm Used
- K-Nearest Neighbors (KNN)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Dataset
**Social Network Ads**
- Input Features: Age and Estimated Salary
- Target Variable: Purchased
- Dataset contains information about users and their purchasing decisions.

## Project Workflow
1. Import required libraries.
2. Load and explore the dataset.
3. Select input and target variables.
4. Split the dataset into training and testing sets.
5. Apply MinMaxScaler.
6. Train the KNN model.
7. Check model accuracy.
8. Make predictions using sample inputs.

- `Social_Network_Ads.csv`
