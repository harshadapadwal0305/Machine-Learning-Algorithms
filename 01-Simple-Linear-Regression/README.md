# Simple Linear Regression – Salary Prediction

## Project Overview
This project uses Simple Linear Regression to predict an employee's salary based on their years of experience.

## Objective
To understand how Simple Linear Regression is used to predict salary using one input feature.

## Algorithm Used
- Simple Linear Regression

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Dataset
**File:** `Salary_Data_1.csv`

The dataset contains 30 records with:
- YearsExperience
- Salary

## Project Workflow
1. Import required libraries.
2. Load and explore the dataset.
3. Select input and target variables.
4. Build and train the Linear Regression model.
5. Display coefficients and intercept.
6. Predict salary.
7. Evaluate the model.
8. Visualize the regression line.

## Project Files
- `Simple_Linear_Regression.ipynb` – Notebook containing the implementation.
- `Salary_Data_1.csv` – Dataset used for training.
- `README.md` – Project documentation.

## How to Run
1. Download or clone this repository.
2. Open the notebook in Jupyter Notebook or VS Code.
3. Install the required libraries.
4. Run all notebook cells.

Machine Learning – Regression
