# Simple Linear Regression – Salary Prediction

## Project Overview
This project uses Simple Linear Regression, a supervised machine learning algorithm, to predict an employee's salary based on their years of work experience.

## Objective
To understand the relationship between work experience and salary and build a basic machine learning model for salary prediction.

## Algorithm Used
- Simple Linear Regression

## Technologies and Libraries
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses `Salary_Data_1.csv`, containing 30 records.

- Input Feature: YearsExperience
- Target Variable: Salary

## Project Workflow
1. Import required libraries.
2. Load and explore the dataset.
3. Select input and target variables.
4. Build and train the Linear Regression model.
5. Display model coefficients and intercept.
6. Predict salary for new data.
7. Evaluate model performance using MAE, MSE and R² Score.
8. Visualize the regression line.

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

Note: Evaluation is performed on the training dataset as this is a basic learning project.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas matplotlib scikit-learn jupyter`
3. Open `Simple_Linear_Regression.ipynb` in Jupyter Notebook or VS Code.
4. Run all cells.
