# Machine Learning Algorithms

Welcome to my Machine Learning Algorithms repository!

This repository contains the machine learning algorithms I have practised and implemented using Python as part of my learning journey in Machine Learning.

The purpose of this repository is to understand different machine learning algorithms through practical implementation using datasets and Jupyter Notebooks.

## Algorithms Covered

### 1. Simple Linear Regression
Implemented Simple Linear Regression to understand the relationship between one independent variable and a dependent variable.

### 2. Multiple Linear Regression
Implemented Multiple Linear Regression using multiple independent variables to predict a dependent variable.

### 3. Logistic Regression
Implemented Logistic Regression for classification problems using Social Network Ads and Obesity datasets.

### 4. K-Nearest Neighbors (KNN)
Implemented the KNN algorithm for classification using the Social Network Ads dataset.

### 5. Support Vector Machine (SVM)
Implemented different SVM models:
- Polynomial SVM (Degree 2)
- Polynomial SVM (Degree 3)
- Linear SVM
- RBF SVM

### 6. Decision Tree
Implemented Decision Tree Classification and used GridSearchCV for hyperparameter tuning.

### 7. Random Forest
Implemented Random Forest Classification and used GridSearchCV for hyperparameter tuning.

### 8. K-Means Clustering
Implemented K-Means Clustering to group mall customers based on their annual income and spending score.
