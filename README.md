# Multiple Linear Regression – Salary Prediction

## Project Overview

This project demonstrates Multiple Linear Regression to predict an employee's salary using two input features: Years of Experience and Age.

## Objective

To understand how multiple input variables are used to predict a target value.

## Algorithm Used

- Multiple Linear Regression

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Dataset

**File:** `Salary_Data_multi.csv`

The dataset contains 30 records with the following columns:

- YearsExperience
- Age
- Salary

## Project Workflow

1. Import required libraries.
2. Load and explore the dataset.
3. Select input and target variables.
4. Build and train the Multiple Linear Regression model.
5. Display model coefficients and intercept.
6. Predict salaries for sample inputs.

## Project Files

- `Multiple_Linear_Regression.ipynb` – Jupyter Notebook containing the implementation.
- `Salary_Data_multi.csv` – Dataset used for training the model.

## How to Run

1. Download or clone this repository.
2. Open the notebook in Jupyter Notebook or VS Code.
3. Install the required libraries.
4. Run all notebook cells.
