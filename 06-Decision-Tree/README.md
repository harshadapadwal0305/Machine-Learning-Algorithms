# Decision Tree Classification

## Project Overview
This project demonstrates Decision Tree Classification using the Social Network Ads dataset.

## Objective
To predict whether a customer will purchase a product based on their age and estimated salary.

## Algorithm Used
- Decision Tree Classifier
- GridSearchCV for hyperparameter tuning

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
**Social_Network_Ads.csv**

- Input Features: Age, Estimated Salary
- Target: Purchased

## Steps Performed
1. Imported the required libraries.
2. Loaded and explored the dataset.
3. Selected input and target variables.
4. Split the dataset into training and testing sets.
5. Applied MinMaxScaler.
6. Built and trained the Decision Tree model.
7. Used GridSearchCV to find the best parameters.
8. Created a final Decision Tree model.

## Files Included
- `DT.ipynb` – Jupyter Notebook containing the implementation.
- `Social_Network_Ads.csv` – Dataset used for classification.

## Project Type
Machine Learning – Supervised Learning – Classification
