# Logistic Regression

## Project Overview
This project demonstrates the implementation of the Logistic Regression algorithm using two different datasets: Social Network Ads and Obesity Classification.

## Objective
To build Logistic Regression models that classify data and make predictions using machine learning.

## Algorithm Used
- Logistic Regression

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Datasets

### 1. Social Network Ads
- Input Features: Age and Estimated Salary
- Target Variable: Purchased
- Purpose: Predict whether a person will purchase a product.

### 2. Obesity Classification
- Input Features: Age, Gender, Height, Weight and BMI
- Target Variable: Label
- Purpose: Predict the obesity category of a person.

## Project Workflow
1. Import required libraries.
2. Load and explore the dataset.
3. Select input and target variables.
4. Encode categorical data where required.
5. Split the dataset into training and testing sets.
6. Apply MinMaxScaler.
7. Train the Logistic Regression model.
8. Check model accuracy.
9. Make predictions using sample inputs.
