# K-Means Clustering

## Aim
To perform K-Means Clustering on the Mall Customers dataset and group customers based on their annual income and spending score.

## Dataset
**Mall_Customers.csv**

The dataset contains customer information, including:
- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

## Algorithm Used
**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm used to divide data into groups called clusters.

## Practical Steps
1. Import the required libraries.
2. Load and explore the dataset.
3. Select Annual Income and Spending Score.
4. Visualize the customer data using a scatter plot.
5. Apply K-Means clustering with 5 clusters.
6. Display the cluster centres.
7. Predict cluster labels.
8. Visualize the final clusters.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
