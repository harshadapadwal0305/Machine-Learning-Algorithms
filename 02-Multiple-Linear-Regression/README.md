# Multiple Linear Regression

## Project Overview
This project demonstrates Multiple Linear Regression, a supervised machine learning algorithm used to predict a continuous numerical value using multiple input variables.

## Objective
To predict an employee's salary based on Years of Experience and Age.

## Algorithm Used
- Multiple Linear Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses `Salary_Data_multi.csv`, which contains employee information such as:
- YearsExperience
- Age
- Salary

## Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Explore the dataset.
4. Select input and target variables.
5. Build and train the Multiple Linear Regression model.
6. Display model coefficients and intercept.
7. Predict salaries using sample inputs.

## Files Included
- `Multiple_Linear_Regression.ipynb` – Jupyter Notebook containing the implementation.
- `Salary_Data_multi.csv` – Dataset used for training.
- `README.md` – Project documentation.

## How to Run
1. Download the project folder.
2. Open the notebook using Jupyter Notebook.
3. Install the required libraries if needed.
4. Run all cells.

## Project Type
Machine Learning – Supervised Learning
